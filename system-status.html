How to read this page
REAL-TIME streamed as it trades (only the Coinbase crypto WebSocket on this site).
DELAYED real prices that are not real-time: Yahoo last sale via the worker (Nasdaq-reported for US stocks, not the consolidated tape; indices and some listings ~15 min), CBOE option chains (15 min).
BATCH computed on a schedule (daily or weekly). The age shown is time since the batch ran, not quote delay.
OK within target · LATE past target, a fallback or the next run should catch up · DOWN failing or missing · IDLE outside its operating hours, not stale.
Targets live in one table in this page's source (TARGETS) so they can be audited. Nothing here is cached by the page: every Re-check reads the live sources again (GitHub job history is held 5 minutes to stay inside GitHub's anonymous rate limit).
