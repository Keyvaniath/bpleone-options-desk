🔍 Pattern Recall
For each recent high-conviction alert, find the 10 most similar prior trades and see how they actually resolved.
How it works: Each new signal is a 22-dimensional feature vector. We compute Euclidean distance to every prior resolved trade and pick the 10 nearest. If 8/10 historical look-alikes won, that's confirmation. If 6/10 lost, that's a red flag — even if the model is confident.
