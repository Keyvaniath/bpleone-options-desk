🧠 What this shows
Every brain finding creates an edge in this graph: from a setup type node to a symbol node. The edge color shows the outcome (green = hit, red = miss, gray = pending). Node size grows with activity. Symbols frequently producing wins on a given setup will have many green edges to that setup's node — this is the visual representation of where the model has the strongest learned edges. Click any node to drill into its findings.
