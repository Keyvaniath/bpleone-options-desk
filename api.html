🔑 Authentication

All REST and WebSocket endpoints require an API key passed as Authorization: Bearer YOUR_KEY.

# Example request curl -H "Authorization: Bearer sk_live_..." \ https://api.options.bpleone.com/v1/quotes/NVDA

🌐 WebSocket Feed

Real-time tick stream. Subscribe to symbols you care about; server only sends matching updates.

WSS wss://api.options.bpleone.com/v1/stream
// Browser example — mirrors the in-site Feed module const ws = new WebSocket('wss://api.options.bpleone.com/v1/stream'); ws.onopen = () => { ws.send(JSON.stringify({ action: 'subscribe', symbols: ['NVDA', 'SPY', 'QQQ'] })); }; ws.onmessage = (e) => { const tick = JSON.parse(e.data); console.log(tick.symbol, tick.last, tick.changePct); };

🪝 Webhooks

Subscribe an HTTPS endpoint and we'll POST events as they fire. Supported events: signal.created, trade.published, flow.unusual.

POST /v1/webhooks
Body: { "url": "https://your-server.com/hook", "events": ["signal.created", "trade.published"], "filters": { "symbols": ["NVDA", "SPY"], "min_score": 80 } }

Each delivery is signed with HMAC SHA-256. Verify the X-Bpleone-Signature header using your webhook secret.
