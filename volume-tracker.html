📊 Volume + Latency
Is the brain actually running? · predictions/hour · resolution latency distribution
📚 What to look for
Predictions / hour:
  • 0: continuous-learner has stopped. Refresh the page.
  • 1-3: normal during slow markets (one tick per symbol per 5min)
  • 20+: all systems firing
Avg latency:
  • ~10 min: normal for short-horizon resolutions
  • > 30 min: resolution loop is slow or skipping some predictions
  • P95 > 60 min: long tail of stale predictions — check the data feed
Unresolved >24h: any number above 5-10 means predictions are getting stuck. Each one ties up a journal entry that won't ever feed the learning loop. Use the brain-truth dashboard to spot which module is failing.
