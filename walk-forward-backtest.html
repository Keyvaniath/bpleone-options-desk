Why this page no longer runs
It replayed the browser model over Stooq's daily history, which a browser can never load (Stooq sends no CORS headers), so every run failed on every symbol. Had it run, it would not have met the desk's honesty rules either:
  • it graded the model against a 50% coin flip, so market drift (stocks rise in a little over half of all 5-day windows) would have read as skill, and it printed "REAL ALPHA" on that basis;
  • it called the replay out-of-sample, but the browser model trains on the same recent bars;
  • it held each trade for one day while the model predicts five.
The honest test is live on the Worker
The Worker brain trains on Yahoo daily history, holds out a walk-forward period it never saw, and grades accuracy against the drift base rate with the overlap correction (daily calls on 5-day windows are not independent).
