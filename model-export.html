🔑 What's in a backup
A backup is a single .json file containing every localStorage key the brain depends on. Restoring it on a fresh device gives you the same predictions instantly — no re-training required. Useful for: switching browsers, migrating to a new laptop, sharing your trained brain with a collaborator, or rolling back after a bad training session.

Backups are tagged with the schema version (v1). Imports refuse to apply if the schema version doesn't match, so you can't accidentally corrupt your state with an incompatible file.
