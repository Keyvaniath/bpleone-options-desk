⏪ Historical Bootstrap
Pre-train the browser brain on real daily bars across 48 symbols so it doesn't start at zero
🎬 Run controls
The bootstrap auto-runs once per browser, 8 seconds after the first page load. Use the buttons below to re-run or reset.
📚 What this does
Without bootstrap, the brain learns purely from going-forward live ticks — meaning ~10 resolved trades per symbol per day. It takes WEEKS for BSS to converge, weeks for calibration to be honest, weeks for per-symbol blends to mean anything.

The bootstrap fixes this:
  1. On first visit, pulls real daily OHLC bars for 48 tracked symbols (broad indices, mega-tech, semis, financials, sector ETFs, bonds, vol, international, crypto). With no key: one request to the desk's Worker returns about 40 finished sessions per equity (Yahoo, the same bars the Worker brain trains on), and Coinbase serves BTC/ETH. A Finnhub key with paid daily-candle access gets ~250 days instead. (A browser can never read Stooq, which sends no CORS headers, so pass 339 retired it; today's unfinished bar is never used.)
  2. For each (symbol, day) pair, reconstructs the same 22-feature vector the brain uses live: RSI, ATR%, vol ratio, distance from 50/200 MA, SPY change, setup flags from price action, etc.
  3. Outcome label = direction over the next 5 sessions (up if the close 5 sessions later is 1%+ higher, down if 1%+ lower, dropped in between; the same horizon the Worker brain uses since pass 218)
  4. Feeds (features, outcome) to every learning module: ModelStore (Adam SGD), Calibrator (Platt), IsotonicCalibrator (PAV), RegimeCalibrator, BrierSkill, SharpeTracker, SymbolSkill, SymbolSharpe, SectorPerf, ReliabilityDiagram, PredictionHistogram, SymbolBias
  5. Fits all calibrators on the populated pools so probabilities become honest immediately
Result: several hundred real training examples on the Worker bars (about 20 usable sessions per symbol after warmup and the 5-day look-ahead, fewer after flat outcomes are dropped), up to ~11,000 with paid candles. It warm-starts the browser model; it does not prove an edge (see the edge scorecard: the TA features show drift, not timing skill).

Gated by localStorage flag (key bumped to v2 in pass 69) so it runs once per browser; the weekly refresh re-runs it every 3 days. When this browser mirrors the Worker brain (worker-setup), both defer to the Worker. A run takes a few seconds on the Worker bars, about a minute with paid candles (paced 1.1 s a call).
