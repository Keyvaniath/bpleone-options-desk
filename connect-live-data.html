📚 Need help getting a key?

Finnhub (fastest, free): go to finnhub.io/register, sign up with email, the API key is on your dashboard immediately. Free tier = 60 calls/min, plenty for the brain.

Polygon (best quality, paid): polygon.io/dashboard/signup. The Starter plan ($29/mo) includes real-time stocks + 5y of historical bars. Indices plan ($49/mo) adds VIX/SPX.

Alpaca (free, IEX-only): alpaca.markets. Sign up for a paper trading account → API Keys → Generate. Free real-time IEX feed (not full SIP).
