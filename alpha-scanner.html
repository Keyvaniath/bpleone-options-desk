How to read this. BUY = the brain leans up and volume is running well above normal (institutional accumulation footprint). SELL = down-lean on heavy volume (distribution / avoid). WATCH = big volume surge but the brain isn't directionally confident yet — something is happening, keep an eye on it. What this is NOT. This is unusual volume + price action on free equity data — the honest TA proxy for institutional activity. It is not options-flow whale prints (sweeps/blocks/premium), which require a paid OPRA data feed. If you want true options flow, that's a data-subscription decision.
