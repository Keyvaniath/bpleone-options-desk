📅 Weekly Bootstrap Refresh
Every 7 days, the historical bootstrap re-runs automatically so the brain trains on the most recent 60 days — no manual click required.
Why this exists: the original Historical Bootstrap only ran once per browser when you first visited. Without refresh, the brain keeps training on the same 60-day window forever and never sees this week's price action. This module fixes that — every 7 days, the bootstrap automatically re-pulls fresh 60-day bars for all 24 symbols from Stooq and re-trains the model, calibrators, BSS, Sharpe tracker, and every other learning module.
🎬 Manual controls
Refresh runs automatically every 7 days. Use these to force a refresh now, or reset the timer so the next refresh waits a full week from now.
