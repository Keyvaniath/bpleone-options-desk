Phase 1

📝 Recording Every Trade

Every trade you ever close gets logged to your browser's localStorage under the key bpleone_learn_v1. The schema is dead simple:

{
  id: 't_1778..._abc',
  ts: 1778788000000,          // open time
  closedTs: 1778799600000,    // close time
  symbol: 'NVDA',
  setup: 'macd-cross',        // or 'bull-flag', 'cup-handle', etc.
  sector: 'Semiconductors',
  bias: 'bull',               // or 'bear'
  vixRegime: 'low',           // captured at OPEN time
  score: 78,                  // the raw score when entered
  entry: 138.27,
  stop: 133.80,
  exit: 143.50,               // filled at this price
  pnl: 521.00,
  R: 1.17,                    // ← THE key metric: pnl / |entry − stop|
  result: 'win',              // 'win' if R ≥ 0
  holdDays: 1.3,
  closeReason: 'target'       // 'target', 'stop', 'manual', 'trail'
}

Where trades come from:

  • paper-trade.html — auto-logs on every fill (closes are R-computed)
  • journal.html — manual entry with full fields
  • setup-wizard.html — guided 6-step builder
  • trade-plan.html — "Save to Journal" button
Seeded with 240 simulated trades so the system has signal from minute one. You can wipe with Settings → Reset → Edge Analytics, and start clean. Real trades dilute the seeds rapidly — after ~50 real closes, the weights start reflecting your edge.
Phase 2

⚖ Base Setup Weights — Updated on Every Close

Each setup type accumulates a list of R-multiples from your closed trades. The base weight is then:

weight = clamp(1 + avgR × 0.3, 0.5, 1.6)

Three real worked examples:

macd-cross · 12 closed trades · sum of R = +7.2 · avg = +0.60R
weight = 1 + 0.60 × 0.3 = 1.18× (boost)
bull-flag · 8 closed trades · sum of R = −2.4 · avg = −0.30R
weight = 1 + (−0.30) × 0.3 = 0.91× (slight fade)
unusual-put · 5 closed trades · sum of R = −4.0 · avg = −0.80R
weight = 1 + (−0.80) × 0.3 = 0.76× (heavy fade)

Clamped to [0.5, 1.6] so the system can amplify or dampen without flipping direction. A bad setup is faded, not made bullish; a good setup is boosted, not made infinite.

Triggered by: Learn.closeTrade(id, exit, reason) → automatically calls Learn.rebalanceWeights() after every close.

Phase 3

🎚 Conditional Weights — by Sector × DoW × Regime

Base weights tell you "macd-cross is good for me." Conditional weights tell you "macd-cross is good for me in Tech on Tuesdays in low-VIX regimes." The same math, partitioned:

// 4 dimensions tracked simultaneously
ctx = {
  sector: 'Semiconductors',
  dow:    'Tue',                // Mon/Tue/Wed/Thu/Fri
  hold:   '1–3d',               // Intraday / 1-3d / 4-9d / 10-29d / 30d+
  bias:   'bull',
  regime: 'low'                 // low/normal/elevated/panic (VIX bucket)
}

// Per (setup × dim × bucket) with n ≥ 3:
adj = clamp(1 + expectancy × 0.18, 0.7, 1.35)

Conditional adjustments are gentler (0.18 vs base 0.30) and tighter-clamped — they refine the base, they don't flip it.

macd-cross in Tech — 14 trades, avg +0.9R
→ adj = 1 + 0.9 × 0.18 = 1.16×
macd-cross on Friday — 6 trades, avg −0.4R
→ adj = 1 + (−0.4) × 0.18 = 0.93×

Triggered by: Learn.rebalanceConditional() — runs alongside rebalanceWeights after every close.

Phase 4

🧮 Score Application — How the Brain Surfaces Insight

When a new setup appears (a momentum scan, an unusual call sweep, an AI Scout idea), the raw heuristic score gets multiplied by base × conditional:

// Live code from learn.js
function adjustedScoreCtx(rawScore, type, ctx) {
  const base = state.weights[type] || 1.0;
  let mult = base;
  for (const dim in ctx) {
    const adj = state.conditional[type]?.[dim]?.[ctx[dim]]?.adj;
    if (adj) mult *= adj;
  }
  return clamp(0, 100, Math.round(rawScore × mult));
}

Worked example — a fresh macd-cross signal on NVDA today:

raw      = 72   (MACD bullish + 50DMA reclaim + 1.84× volume)
base     = 1.18× (macd-cross has +0.6R avg in your history)
sector   = 1.16× (Tech has been favored for this setup)
dow      = 0.93× (Friday slightly worse)
regime   = 1.06× (low-VIX regimes have edge for you)
hold     = 1.04× (1-3d holds are your sweet spot)
─────────────────
final    = 72 × 1.18 × 1.16 × 0.93 × 1.06 × 1.04
         = 95   (clamped to 100)

You see this score on: Plays of the Day, Live Signals, Trade of the Day, Ticker Focus, AI Scout (Claude sees the learned weights and uses them in its reasoning), and Trade Plan Generator.

You can call it from the browser console anytime:

Workflow

🎯 How To Actually Train It

The brain only gets smart if you feed it. Here's the 4-week shakedown to get the weights tuned to your edge:

  1. Week 1 — Paper trade aggressively. Hit paper-trade.html daily during market hours. Aim for 3-5 trades a day. Every close auto-logs.
  2. Week 2 — Add real (small) trades. If you find a setup with high learn-adjusted score and your discipline is clear, take it. Log it via journal.html the moment you close.
  3. Week 3 — Audit the brain. Open learn-dashboard.html at week-end. Look at base weights — anything fading hard? Anything boosted? Match it against your gut.
  4. Week 4 — Trust + size up. By now you have ~80-100 closed trades. The conditional weights start telling you specific facts ("bull-flag on Mondays underperforms by 0.3R for me"). Trust the brain, size up the high-score setups, fade the low-score ones.
Rule of thumb on data volume:
• 0-20 trades → ignore the score, you're still seeded
• 20-50 trades → base weights starting to matter
• 50-100 trades → base + sector + DoW have signal
• 100+ trades → all 4 dimensions reliable, this is YOUR edge model

What to journal carefully: setup type (use the dropdown — don't make up new ones), sector, entry, stop (this defines R!), exit, and close reason. The R-multiple is the entire engine — if you don't log the stop accurately, the system can't learn.

Honest Caveat

⚠ This is NOT a Black-Box ML Model

The bpleone "brain" is not a neural network. It's an expectancy-tracking heuristic with conditional bucketing. Here's what that means for you:

  • ✅ Transparent — every adjustment is auditable. Call Learn.explain() and you see the multipliers.
  • ✅ Fast — scoring is microseconds. No model loading, no inference cost.
  • ✅ Personalized — your trades shape your weights.
  • ⚠ Doesn't discover novel patterns — it can't tell you "macd-cross combined with 200DMA reclaim AND > 2× volume" is better than either alone. It scores what you tell it to score.
  • ⚠ Requires honest journaling — garbage in = garbage out. If your setups aren't labeled accurately, the weights drift to noise.
  • ⚠ Doesn't backtest — it's forward-only. The seeded 240 trades are a cold start, not history.

If you want true ML (gradient boosting, ensemble models, walk-forward analysis), that's a roadmap item. For now this engine is honest, fast, and personalized — which beats most retail "AI" products that just rebrand RSI as "neural pattern detection."
