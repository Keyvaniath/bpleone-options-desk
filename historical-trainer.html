🎓 Historical Trainer
Train the brain on REAL past market data · pulled from Stooq · honest features and outcomes · --
What this does: Fetches the last ~90 trading days of daily OHLC bars for every symbol in the universe from Stooq.com (free, no key, CORS-friendly). For each historical day, computes the same 22 features the live brain uses — but from real bars, not random numbers. Labels each by whether the next-5-day return was positive or negative. Trains the brain on this real dataset.

Why this matters: The original auto-seed generated 200 random rows. The brain learned nothing useful and reported high confidence anyway. Historical training fixes this — every example is from real price action that actually happened.

Cost: 22 symbols × 1 CSV each = 22 HTTP requests to Stooq. Total ~5 seconds. Stooq has no rate limit but be polite — don't run this more than once per hour.

🔬 What the model learns
For each historical day per symbol, we compute:
• RSI(14) from real close history
• ATR% from real daily ranges
• Distance from 20/50 MAs from rolling averages
• Price-relative-to-prevClose %
• Day range / body / wick as % of ATR

The label is the simplest possible signal: did the close 5 trading days later exceed today's close? Yes = label 1 (win), No = label 0 (loss). The brain learns which feature combinations predict that.

After training, the brain has real ground-truth knowledge of "what RSI + MA distance combinations preceded next-week winners over the last 90 days" — actual signal from actual market behavior.
