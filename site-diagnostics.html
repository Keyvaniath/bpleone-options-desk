🔧 If something failed
  • Browser checks failing: your browser may be blocking JS, cookies, or localStorage. Try Chrome/Edge/Safari with default settings.
  • Core modules missing: the page didn't load fully. Try hard refresh (Ctrl+Shift+R or Cmd+Shift+R).
  • Brain modules missing: they lazy-load via js/live.js. Give the page 5-10 seconds to finish loading, then re-run.
  • LocalStorage full: use the "Clear brain state" button below. This resets all learning history but the brain re-trains in a few minutes.
  • Notification permission denied: not a problem — alerts just won't fire. Re-enable in browser settings → Site Settings → Notifications.
